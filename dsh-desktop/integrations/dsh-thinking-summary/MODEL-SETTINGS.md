# 摘要模型设置

版本：1.1.2-local.1。在 DSH Web 设置 → 思考摘要中配置，使用 DSH 已有的提供商连接，不新增密钥输入。

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| 摘要提供商 | 自动 | 沿用原版规则，选择首个可用 Flash 模型；也可指定提供商 |
| 摘要模型 | 自动 | 在指定提供商内自动选择 Flash，或手动选择该提供商列出的任意模型 |
| 输出 token 上限 | 500 | 整数，64–8192；数字输入框失去焦点时保存 |
| 最大尝试次数 | 2 | 整数，1–5，包含首次调用；1 表示失败不重试 |
| 摘要思考模式 | 自动 | 支持 `off` 时关闭思考，否则使用所选提供商默认设置 |

页面显示当前实际解析出的提供商与模型。手动选择不存在或不可用的模型时明确报错，不静默退回其他提供商或模型。若提供商没有 Flash 模型，请手动选择具体模型。

模型与参数修改会应用于后续开始的摘要调用；已经开始的一次调用及其重试保持同一份参数快照，已经完成的摘要不重新生成。提供商/模型目录接口只返回名称和 ID，不返回密钥或连接配置。

已通过12项后端回归测试：原兼容接口、实时设置、摘要去重、历史跳过、错误反馈，及手动模型/输出上限传递、关闭思考、精确尝试次数、失败重试成功、切换不使用旧缓存、失效模型不回退、参数范围与目录字段白名单。真实宿主与界面验证结果另记入 COMPATIBILITY.md。
