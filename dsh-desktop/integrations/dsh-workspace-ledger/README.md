# 对话任务账本与恢复

面向当前 DSH Web 0.2.2-rc.1 的本地插件。以 fenglufa/dsh-board 的 MIT 纯任务数据核心为基础改造，来源和固定提交见 UPSTREAM.md。

## 查看与使用

- 顶部「任务账本」标签直接显示当前对话的任务。左侧底部「对话任务账本」可按工作区浏览多个对话。
- 按工作区查看对话；选中对话后查看其中的任务，再选择任务查看目标、约束、完成与剩余事项、检查点、文件变化和关联对话。
- 点击「整理本对话任务」后，从早到晚分段处理本次快照中的用户与助手正文，以及工具结果摘录。进度条显示已处理段数。所有分段通过校验后统一保存。失败时，在 DSH 未重启且记录和模型设置一致的情况下，重试可从失败段继续。旧版标记为部分整理的会话可以重新运行全量整理。
- 在账本右上角的「设置」中选择 DSH 已配置的提供商和模型，调整输出上限（512–8192 tokens）。默认模型为 deepseek-official / deepseek-flash，默认上限为 2400。模型支持 `off` 时关闭思考，其余使用提供商默认设置。设置写入当前 DSH 配置，在下一次需要调用模型的历史整理中生效。常规任务记账由当前主 Agent 的工具调用完成。
- 打开恢复详情不会派发任务；“继续原对话”或“新对话接手”才发送继续消息。关联对话忙碌时禁止重复派发，状态未确认时不自动重发。

可直接对 DSH 说：

> 请为这项多步工作建立任务账本，记录目标和验收标准。每完成一个重要阶段，记录检查点、剩余事项、下一步和文件证据；中断前也记录当前状态。

或：

> 查询这个工作区的任务账本，告诉我当前对话有哪些未完成任务，并只读查看恢复信息。

## 进度与证据的含义

“已完成事项”和“已结束”是 Agent 或历史记录的报告，不自动等同于验收通过。文件核对只验证文件存在和变化。32MiB以内文件比较SHA-256，更大的文件只比较元数据；内容正确性仍需对应验收步骤。

同一个任务可以由多个对话接力，因此会在多个关联对话下出现；任务ID与账本记录仍是同一个。工作区路径已删除的对话会计入不可用路径提示，不能直接启动恢复。

## 交付物验收与经验入库

- 「智能验收与复盘」将两个步骤串在一起。输入可选的核对重点后，模型根据任务目标、原始要求和交付物安排检查。可直接验证的标准交给程序，其他标准结合可引用的交付证据核对。验收报告先保存，之后生成整改建议和经验草稿。浏览器可重新打开详情查看运行阶段。经验卡沿用预览、勾选、确认入库的步骤。

- 选中任务，在详情区打开「交付物验收」。核对或补充标准，再指定账本已登记的交付物。支持文件存在、PDF 解析、文本匹配、非空行数和文本摘录的模型核对。需要运行命令的检查可由管理员在该插件配置的 `reviewCommands` 中登记 `{id, label, executable, args}`。`executable` 使用绝对路径，点击开始验收时在任务工作区运行。
- 验收结论、各条标准及证据独立保存。任务版本或已登记文件发生变化后，详情会提示重验。模型无法给出可回读的引用时，该项显示待人工核验。
- 「经验整理与入库」使用检查点、验收报告与相关对话摘录起草经验。可查看依据、编辑和保存卡片，再预览正文，勾选并确认写入。没有可核对来源的草稿留在账本中。
- 已确认的卡片作为 Markdown 资源写入本机 OpenViking 的 `viking://user/default/resources/ledger-experience/`。资源按工作区和内容哈希区分。回执逐步记录提交、回读和检索结果。同一张卡可重新勾选以核对回执，目标地址保持一致。

恢复不会回滚文件、修复旧日志、自动重复外部发送或安装。上下文压缩与中断标记会保存到事件记录；后续有用户输入时，主 Agent 会拿到当前对话的活动任务索引并按需查询详情。

## 数据

账本放在 DSH_HOME（默认 ~/.dsh）下的 workspace-ledger/，每个真实工作区对应独立哈希文件。JSON原子写入并保留上一版 .bak，更新检查版本；损坏时报告错误，不覆盖成空账本。插件不修改 DSH 自身会话日志。

这份账本与 OpenViking 的长期经验互补。插件不额外遍历全部账本向 OpenViking 提交；原有记忆插件的自动捕获按其自身设置运行。

## 模型工具

- ledger_create：在当前对话所属工作区创建任务。
- ledger_query：列出任务摘要与版本，指定 taskId 可读详情。
- ledger_checkpoint：保存阶段记录、阻塞、下一步和证据文件，携带 expectedVersion 防止覆盖新检查点。
- ledger_recovery_info：只读查看恢复摘要，不开始任务。

## 安装与卸载

安装：通过官方 dsh plugin --profile web add file: 指向本目录，重启 Web 并刷新。卸载使用 dsh plugin --profile web rm @local/dsh-workspace-ledger，重启后移除入口和工具；已有账本保留。

源代码回归：node --test test/*.test.mjs。功能清单见 FEATURES.zh.md，真实宿主验收结果在实际测试后另记。
